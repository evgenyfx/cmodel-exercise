# Default input: Lena, 8-bit monochrome Y4M

`lena_mono.y4m` contains a single 512 x 512 uncompressed monochrome frame. Its header specifies `Cmono`, followed by `FRAME` and 262144 pixel bytes. The complete file is 262189 bytes.

Source: the 512 x 512 [Lenna standard test image](https://en.wikipedia.org/wiki/File:Lenna_(test_image).png)
